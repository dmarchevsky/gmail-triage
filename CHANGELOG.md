## [1.0.0] - 2026-10-20

First versioned release. It covers everything built before versioning began.

### Features
- **Gmail ingestion**: OAuth with encrypted tokens and a send-incapable scope guard.
  `historyId` polling, or real-time push through `users.watch` and a Pub/Sub pull
  consumer, with a catch-up sweep. Configurable mailbox scope (inbox plus the Gmail
  category tabs).
- **Classification**: a per-email queue classifies mail against plain-language
  category criteria, in the order ignore list, then hard rules, then model. There are
  two switchable backends:
  - a local OpenAI-compatible **generative LLM**: JSON-schema constrained, and it
    writes the per-email summary in the same call;
  - a System One **decider** model (e.g. halogen d3-nano) that returns real category
    probabilities, with a side-by-side preview of both backends.
- **Rules**: label, mark read, archive and trash actions, each rule with its own
  dry-run flag. Gmail labels are first-class, with colored system labels. Bulk
  reclassify and rule re-runs.
- **Digests**: scheduled and threshold-triggered digests in assemble or synthesize
  mode, delivered to Telegram (with optional collapsed sections), the in-app Digests
  inbox, and Web Push.
- **Feedback loop**: corrections produce proposed criteria revisions, including
  source-category exclusions, for you to approve, edit or reject. Criteria are
  versioned, with history and diffs. Per-category precision stats.
- **Web UI**: dashboard, emails, categories, rules, labels, digests and settings. A
  first-run wizard, a mobile layout, and an installable PWA with deep links. LLM
  prompts and model settings are editable, with a model picker filled from the
  endpoint.
- **Operations**: PostgreSQL storage, a retention policy, recovery of stalled emails
  and digests, config export/import, and a danger zone (purge / factory reset).
  Telegram alerts when Gmail auth fails.
- **Security**: remote access through a Cloudflare Tunnel plus Cloudflare Access
  (Google sign-in), with the Access JWT verified in-app. `DEV_AUTH` for local
  development only.
